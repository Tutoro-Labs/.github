# Tutoro Labs defaults

Organisation-wide defaults for every repository of Tutoro Labs that has none of its own:

- **Issue forms** (`.github/ISSUE_TEMPLATE/`) for the issue types Epic, Feature, User Story, Task and Bug; each form
  sets its issue type.

Work item hierarchy: Epic → Feature → User Story → Task, linked as sub-issues; a Bug sits under the story or feature it
belongs to, or stands alone. New projects start from the organisation's project template "Scrum template".
